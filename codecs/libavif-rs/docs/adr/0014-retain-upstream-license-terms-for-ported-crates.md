# Retain upstream license terms for ported crates

Accept the primary upstream licenses identified in the
[native license inventory](../NATIVE-LICENSES.md), including BSD-2-Clause,
BSD-3-Clause, BSD-3-Clause-Clear, and Apache-2.0. Preserve the original terms,
attributions, and applicable license, notice, and patent material for imported
and mechanically translated sources. A common repository does not make every
future crate BSD-2-Clause.

The desired simplification is a planning input, not a decision to relicense all
upstream code uniformly. A shared presentation and notice-generation convention
is a candidate for that simplification. The license of new original additions
and any broader relicensing proposal still need a concrete scope and decision.
Additional transitive terms, including the configured AVM ML dependency graph,
remain subject to a separate scope decision.
